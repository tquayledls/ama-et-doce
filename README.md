# Ama et Doce

*Ama et doce* ("love and teach"): a free, non-commercial Catholic study site at
<https://tquayledls.github.io/ama-et-doce>. Each day it publishes a Saint of the Day with a short life,
a painting, a famous excerpt, and uses for catechesis, apologetics, theology and prayer, with
every claim footnoted, plus Church Fathers readings and *Summa Theologiae* articles.

The site is static HTML generated by the Python scripts in `saints/tools/`. Daily pages are
committed to `saints/site/`, and GitHub Pages redeploys on every push to `daily` (see `.github/workflows/pages.yml`).

## Building the site

```bash
python3 saints/tools/build_site.py
```

See `saints/SAINTS_PLAN.md` for how each day's page is produced.
